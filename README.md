# Sista Rootz Website

Coming-soon announcement site for Sista Rootz / M.Q LLC.

## Overview

This first version is a static, responsive website for adults 21+ that presents
Sista Rootz as a spiritual and wellness-centered cannabis dispensary preparing
to open in late August.

The site includes:

- 21+ age gate with birthday confirmation
- Hero announcement using the Sista Rootz logo and storefront artwork
- About section honoring Sista Ruth
- Planned "What's Coming" categories
- First-time visitor guidance
- Placeholder update form with no backend
- Contact and vendor inquiry placeholders
- Footer disclaimer noting no online ordering is available yet

## Local Preview

Open `index.html` directly in a browser, or run a simple static server:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Notes

This is not an ecommerce site. It does not include checkout, payments, carts,
live inventory, online ordering, or a connected form service.
