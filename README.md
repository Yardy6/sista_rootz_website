# Sista Rootz Website

Fresh Next.js/Tailwind coming-soon site for Sista Rootz / M.Q LLC.

## Source References

- Sista Rootz Brand Book
- Gmail website information PDF
- Sista Rootz logo asset

## Local Development

```bash
npm install
npm start
```

Visit `http://localhost:3000`.

For a production-style local run, build first and then start the compiled site:

```bash
npm run build
npm run start:production
```

## Routes

- `/`
- `/about`
- `/first-time-buyers`
- `/menu-shop`
- `/contact`

## Scope

This is an announcement and under-construction website for adults 21+ only. It
does not include ecommerce, carts, checkout, live inventory, payments, online
ordering, POS, or a connected form backend.
